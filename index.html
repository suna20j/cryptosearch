Wichtige Grenzen & Sicherheit
• Die App kann keine fremden privaten Schlüssel finden und keine fremden Wallets öffnen.
• Es gibt keine vollständige öffentliche Liste aller Wallet-Adressen. Der Auto-Scan prüft nur Adressen, die in einem aktuellen Block auftauchen.
• Guthaben ist öffentlich sichtbar, aber kein Zugriff auf die Coins möglich.
• Keine Seed-Phrase, Passwörter oder Private Keys eingeben. Die App fordert diese niemals an.
• Öffentliche RPC-Dienste können Anfragen begrenzen; dann wird ein Fehler angezeigt.
Datenquellen: Blockstream Esplora · Ethereum JSON-RPC · Solana RPC · XRPL Public API
